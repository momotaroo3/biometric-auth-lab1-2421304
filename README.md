3. Why is a perfect fingerprint system impossible?
because physical finger impressions naturally vary every time due to changes in position, rotation, pressure, and skin condition. Also, there is an unavoidable trade-off between falsely locking out real users and accidentally accepting impostors.
5. Where could this kind of system be used, and what could go wrong?
could be used for secure door access in an office building or for smartphone unlocking. However, it could fail if a user's finger is dirty, wet, or cut, or if an attacker attempts to spoof the sensor using a fake physical replica or gummy finger.
